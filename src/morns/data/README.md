# ZIP approximation data

`2025_Gaz_zcta_national.zip` is the U.S. Census Bureau 2025 ZIP Code Tabulation Area Gazetteer file. MORNS uses its representative latitude and longitude fields for local, approximate ZIP-based receiver setup.

Source: https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2025_Gazetteer/

ZCTAs are statistical approximations of ZIP delivery areas. Some ZIP codes, including some PO-box-only codes, may not have a corresponding ZCTA.
